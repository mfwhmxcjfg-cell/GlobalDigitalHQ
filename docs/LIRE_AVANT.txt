GLOBAL DIGITAL HQ — COCKPIT 1.3.1

1. Fermer l'ancienne instance de Global Digital HQ.
2. Depuis l'ancienne version, exécuter « python -m gdhq backup » pour sauvegarder la base avant ouverture avec la nouvelle version.
3. Extraire cette archive dans un nouveau dossier et lancer PREPARER_WINDOWS.cmd.
4. Lancer GlobalDigitalHQ_Next/LANCER.cmd puis ouvrir http://127.0.0.1:8824.
Python 3.11+ doit être installé. Aucune installation de dépendance ni connexion externe par ce préparateur.
Les données restent dans le répertoire Next existant (%LOCALAPPDATA%/GlobalDigitalHQ_Next/data, sauf GDHQ_DATA_DIR personnalisé). Ne pas faire tourner deux instances sur la même base.

La base originale et ses ressources sont conservées dans base_originale.zip. La préparation applique uniquement le patch du cockpit. Aucun fichier de données n'est fourni ou écrasé par le paquet. La première ouverture ajoute la table de tâches manuelles. Les migrations/reprises existantes Next restent applicables.

Retour arrière : fermer la nouvelle version et relancer l'ancienne. La table supplémentaire est ignorée par l'ancienne version. Restaurer la sauvegarde si nécessaire, sans instance ouverte.

ÉCRANS
Tâches : tâches manuelles affectées à un profil, À faire → En cours → Revue → Terminé. Preuve obligatoire pour revue, validation et blocage. Elles ne déclenchent pas d'IA.
Agents : états dérivés des tâches automatiques persistées. Les profils ne sont pas des processus IA indépendants.
Mémoire : notes et sources déclarées par le propriétaire, conservées par projet. Pas de recherche sémantique ni d'injection automatique dans les prompts.
KPI : mesures datées, unité et provenance déclarée. Zéro et absence de données sont distincts. Pas de ventes prétendument vérifiées.
Gates : décision locale du propriétaire. L'approbation ne déclenche aucune action externe.
Connecteurs : Apper.io et Creatikk.io sont des options manuelles non connectées. Aucun adaptateur n'est implémenté et aucune installation native n'était disponible pour eux pendant cette session.
Journal : opérations locales, changements de tâches, décisions, ajouts de mémoire/KPI. Journal SQLite modifiable par l'administrateur du PC, pas un registre infalsifiable.

Le moteur IA exige LM Studio déjà installé et démarré, un modèle sélectionné et le mode pause désactivé par le propriétaire. Les tests utilisent des réponses simulées, pas un modèle réel.
