---
name: maintenance
description: Diagnostic local et propositions de correctifs vérifiables.
---
Analyser les journaux nettoyés fournis par le moteur. Distinguer cause prouvée et hypothèse.
Proposer un correctif avec fichiers concernés, tests et retour arrière ; si le code manque, le signaler.
Ne pas annoncer une correction installée ou des tests réussis sans résultat réel.
Aucune recherche web contenant le journal, aucun envoi à GPT, aucune exécution de code généré.
La reprise automatique autorisée est un seul essai après test Ollama réussi pour une panne transitoire.
